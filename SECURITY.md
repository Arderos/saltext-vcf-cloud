# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** link on the repository Security
page. This creates a private advisory visible only to the reporter and the
maintainer. Do not open a public issue for an unpatched vulnerability.

Include the affected version, Salt and vCenter versions, a minimal reproducer,
the expected impact, and any suggested mitigation. Remove credentials, private
keys, internal hostnames, addresses, and customer data from the report and its
attachments.

You should receive an acknowledgement within seven days. Publication and fix
timing will be coordinated through the private advisory.
